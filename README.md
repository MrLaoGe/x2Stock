# x2Stock

Windows x64 免安装研究工作台，目前提供简体中文、繁體中文、English 空工作台和更新检查。尚无行情、采集、数据库、研究 Agent、回测或交易功能。

完整下载项目后双击根目录 `启动.bat`。必须包含 `desktop-runtime/win-x64` 的真实运行资源；Git 克隆需安装 Git LFS 并执行 `git lfs pull`。无需安装 Node、Python 或 Docker 即可启动。

用户设置保存在独立用户目录。凭据、数据库和个人研究记录不随本仓库分发。更新下载与应用前会校验版本、确切提交和运行资源；安装需要用户确认。

阅读 [用户文档](https://github.com/MrLaoGe/x2Stock/blob/main/docs/README.md)、[贡献说明](https://github.com/MrLaoGe/x2Stock/blob/main/CONTRIBUTING.md)、[更新记录](https://github.com/MrLaoGe/x2Stock/blob/main/CHANGELOG.md)及 [MIT 许可](https://github.com/MrLaoGe/x2Stock/blob/main/LICENSE)。当前 EXE 未签名，0.x 为预发布。
