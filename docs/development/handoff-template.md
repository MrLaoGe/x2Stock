# 模块交接模板

复制为 `docs/development/handoffs/<任务ID>-<模块>.md`，用实际结果填写，不保留含糊的“已完成全部”。

## 任务

- ID / 模块 / 日期 / 分支：
- 用户目标和本轮交付边界：
- 前置决策 / ADR：
- 老板 / PM / 专业对话 ID、父任务、授权来源和范围：
- 业务专责 / 实现责任 / 指定独立验收；依赖和共享文件所有者：
- 基线 SHA / 独立 worktree / 分支；实时记录位置（不提交运行数据）：
- 快照 / 截止 / 方法与策略版本；不适用明确写明：

## 最终状态

| 能力 | 状态（已实现 / 设计确定 / 未验证 / 延后） | 产物和证据 |
| --- | --- | --- |
| 填写能力 | 填写状态 | 文件、提交或验证结果 |

## 输入输出与兼容

- 输入数据、来源、权限、日期、单位、复权和缺口：
- API / 数据结果 / 页面 / 任务输出：
- 用户归属与 secrets 边界：
- 旧资产复用和来源排除；新旧隔离：
- 版本与迁移影响：

## 验证

- 执行命令和结果；失败场景：
- 迁移数量、校验摘要、幂等/断点/回滚（如适用）：
- 独立评审发现及修复：
- 候选版本、退回证据、修订和复验；取消请求与确认停止分别记录：
- 发布锁持有者、最新主线集成和版本协调；异常恢复事实核对：
- 发布状态（本地 / 已提交 / 已推送）与可验证链接：

## 下一轮

- 已知问题及影响：
- 未核验假设与下一项证据：
- 下一任务 ID / 文档 / 推荐操作：
- 必须保护的本地修改或数据：
