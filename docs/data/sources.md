# 数据来源与能力边界

状态：阶段 0 设计；未实现适配器、探测器或采集服务。配置见[配置说明](../configuration.md)，统一字段与错误语义见[接口契约](../contracts.md)。

## 来源政策

仅允许 `tushare`、`eastmoney`、`cailianshe` 三个 provider ID。zhitu、mairuiapi 的接口、配置、历史数据和依赖其数据的结果均排除；新浪、同花顺等未授权来源也不进入新版。不得以“public”“本地缓存”“旧路由”代替实际来源身份。

| 来源 | 计划承接的能力 | 接入与限制 | 首轮需要核验 |
| --- | --- | --- | --- |
| Tushare | 证券主表、交易日历、日行情、日基本面、复权因子、指数历史；权限允许时的行业成员、资金流、涨跌停池 | 后端 HTTP API；用户自行配置 `TUSHARE_TOKEN`；权限和频次因账户与接口而异 | 当前账户逐接口权限、字段单位、可获取日期、分页与限频 |
| 东方财富 | 公开行情、板块和成员、资金流、公告、公开快讯 | 后端适配公开接口；可能出现限流、字段变化、停用和不完整返回 | 全量分页覆盖、行情延迟、板块分类、历史成员是否真实可得 |
| 财联社 | 电报事实、发布时间、原文链接及可用的关联实体 | 后端公开数据适配；公开可见不代表稳定服务或可再分发 | 翻页和历史范围、时间与修订行为、来源条目标识 |

能力矩阵是待核验的设计范围，不表示所有接口已经可用。Tushare 文档入口为[官方文档](https://tushare.pro/document/2)；具体接口依据在对应模块实施时登记，禁止把某次旧调用成功当作当前权限证明。

## 统一适配边界

- 页面、Agent、指标和 worker 通过新版数据访问层读取；适配器负责实际 provider 请求，不允许下游自行增加备用来源。
- 每个能力登记接口名称、响应版本、证券/板块标识、单位、时间、分页、权限、限频、重试和映射规则。请求日志只保留脱敏参数和接口标识，禁止记录 token、密钥、带凭据 URL。
- 首轮采集采用 HTTP；MCP 可用于后续获授权的交互研究，不作为采集必需依赖，也不提交带 token 的 MCP 配置。
- 只有已核验的允许来源可以回退。无可用回退时保留最后有效记录并标记过期；不得把缓存数据改写为实时数据、将缺失记为零或用空响应删除已有数据。
- 状态分别表达权限不足、限流、上游故障、返回不完整、没有数据、过期及正常。请求成功与数据质量通过是两个判定。

后续 `/api/v1` 接口只输出业务字段、来源、质量及时间信息；provider 密钥和迁移源路径不返回前端。示例和字段遵循[接口契约](../contracts.md)，不在本阶段实现端点。

## 原始、派生、AI 分层

| 层级 | 保留内容 | 不能混淆的边界 |
| --- | --- | --- |
| 原始事实 | provider 记录、脱敏请求元数据、实际采集时间及来源证据 | 标签只是溯源线索，不能证明数据真实或正确 |
| 规范数据 | 单位和编码转换后的事实及对应原始记录关系 | 日期、证券范围和调整方式必须一致；不能填入无法证明的字段 |
| 指标/重建结果 | 输入版本、方法版本、截止时间、缺失与覆盖率 | `tushare_derived` 涨跌停成员是推导名单，不是官方原始名单 |
| AI 解读 | 模型、提示/规则版本、证据引用、审查结果 | 解读和角色投票不修改事实；旧AI结论不作为来源真实性证明 |

基础证券使用交易所与证券代码共同标识，板块标识保留 provider 与分类版本；不能仅用六位代码或板块中文名称合并。Tushare 成交量、成交额、市值与股份数量必须显式转换单位，并保留原单位与转换规则，禁止根据数量级猜测。

## 时间与量化适用性

采用[接口契约](../contracts.md)定义的业务事件、首次可用、实际采集、导入及版本时间。所有时间带时区；A 股业务日按 `Asia/Shanghai` 与交易日历解释。

历史记录的交易日不等于投资者当时可获取该记录的时间。导入时间不能充当历史首次可用时间；没有证据的首次可用时间保持未知，并标记不具备 point-in-time 证明。日后获得的修订、成员分类和AI解读不能回填到过去的交易决策中。

保留未复权价格与实际复权因子；历史回测只用截止时间当时可用的因子和调整规则，不用未来因子回算过去输入后声称不存在未来信息。行业/概念成员采用有证据的有效区间和可用时间；按当前成员重建过去只能标记重建，不能当作当时成分。

## 核验与发布边界

实现前用合成数据检验单位、编码、时间和失败行为，再在用户本地进行有凭据的只读能力探测。分别记录接口连通、权限、完整性与历史可用性；不能因网络故障判定接口永久不存在。

数据和新闻正文不随 MIT 代码发布。公开仓库仅保留接口描述、空配置、合成样例和测试。长期保存、个人使用和再分发是不同权限问题，按来源条款在模块实施时确认；仓库许可不授予第三方数据的再分发权。
