# 界面设计基线

状态：阶段 0 设计，尚无网页实现或真实截图。采用 Ant Design 的常规浅色桌面工作台；规范用于后续逐模块开发，模块取舍见 [功能清单](modules/catalog.md)。

## 六个导航入口

| 入口 | 主要内容 | 路由设计基线 |
| --- | --- | --- |
| 市场总览 | 指数、市场宽度、成交、情绪、资金与热点 | `/market` |
| 行情研究 | 股票搜索、行情、个股/板块分析与关联资料 | `/research` |
| 新闻与事件 | 电报、公告、新闻关系、大事件日历 | `/news` |
| 我的研究 | 自选、股票池、笔记、提醒与个人交易记录 | `/my` |
| 报告与复盘 | 盘前/盘中/盘后报告、证据和历史评估 | `/reports` |
| 系统设置 | 数据中心、来源/AI 配置、质量、导入、采集与任务 | `/settings` |

这是导航归并，不是删除特色指标。资金、热力图、拥挤度、主线日历等可由市场或行情研究页的二级视图进入；个股研究是行情研究子页面，个人操作连接“我的研究”。数据中心、任务、AI 和数据质量入口归系统设置。Skill 蓝图先转为开发文档资产，是否有必要提供用户能力图谱保留待审查。

首个已实现入口作为默认页。尚未开发的模块不填造数据、不模拟成功；可提供明确的未实现说明与设计链接。阶段 0 只有文档，不创建空壳应用。

## 桌面布局和信息层级

- 左侧固定六入口导航，顶部放当前模块、必要搜索和本地空间提示；内容区使用页标题、少量关键指标、可筛选表格与详情面板。
- 默认浅灰背景、白色内容面板、清晰边界和统一间距，采用组件库基础排版。避免像素字体、角色立绘、夸张粗边框和背景纹理成为业务页面主体。
- 数据密集模块先给关键判断与数据状态，再提供细节表格和证据；优先复用表格、筛选条、状态提示、图表容器、详情抽屉与任务进度组件。
- 页面拆分为路由模块、领域组件和共享组件。查询状态交给 TanStack Query；表格筛选与可分享的时间范围进入 URL，不将整个应用藏在单一 `tab` 状态中。

## 真实状态和可解释展示

每个重要数据块展示统计时点、采集时间、来源与状态；详情可展开口径、缺失、计算方法和证据。不能只显示“东方财富”就让用户认为已经校验真实性，也不能把派生或 AI 解读标为直接行情。

加载、无查询结果、字段缺失、权限不足、过期缓存与服务失败分别展示。刷新失败保留上次有效数据并注明时间；空值用 `—` 并解释原因。显示 `0` 时必须是实际零值。不要用刷新动画或刚更新的页面时间掩盖数据陈旧。

A 股涨跌使用红涨绿跌，且同时给出正负号、文字标签或实际数值，颜色不成为唯一信息渠道。风险、任务状态和置信度使用独立语义，避免把红色风险与红色上涨混为一谈。图表显示单位、图例、时间与可访问的数据表；已复权、未复权、估算与正式数据均有明确标记。

新闻卡片区分事实引用、来源差异、规则评分和 AI 解读。报告展示生成版本、时间截止、输入证据、假设、失效条件与待复核项；不以多个角色意见相同作为可信度徽章。

## 个人操作与移动布局

首期个人操作包括股票池管理、收藏/已读、监控阈值与提醒确认等已进入模块范围的功能；交易记录录入是否保留见模块审查。表单提供即时校验、保存结果和失败重试，不让页面轮询覆盖未保存输入。确认提醒前展示将改变的阈值或状态，具体规则以个股模块契约为准。

窄屏折叠侧栏，主要操作保持可点击，指标变为单列或两列，表格允许横向滚动并固定识别列；详情抽屉改为适合窄屏的面板。搜索、股票池、收藏、提醒与报告阅读应可用，不要求手机重现全部桌面图表密度。

移动适配不等于已经提供远程访问。首期仅本机部署，手机跨设备访问须等待认证和网络部署能力，见 [架构边界](architecture.md)。密钥输入只返回配置状态及遮蔽信息，不回显明文，不让用户在网页中选择内部运行权限。

## 后续页面验收

- 在桌面与窄屏验证导航、阅读和个人操作；键盘能定位表单和主要动作。
- 用合成 fixtures 覆盖加载、无记录、空值、过期、失败、冲突和计算结果；每个值的单位和状态可辨认。
- 查询切换和后台刷新不串用旧筛选结果、不清空有效数据、不重置未保存表单。
- 尚未实现的模块、未核验来源和不可回放报告均有准确说明；视觉完成后再进行业务与归属验收。
