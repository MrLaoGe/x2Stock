# 数据与接口契约

状态：阶段 0 设计契约，示例不对应现有可调用接口。具体端点、数据库表和严格校验随模块实现补充；本文固定跨模块必须一致的语义。参见 [架构](architecture.md)、[数据源](data/sources.md) 与 [迁移设计](data/migration.md)。

## API 和读取结果

API 统一使用 `/api/v1` 前缀。Pydantic 契约产生 OpenAPI，前端类型来自同一接口定义，避免人工维护两套含义不同的字段。普通查询不隐式采集、生成报告或调用付费 AI；执行操作显式提交任务。

数据查询结果必须包含实际 `data`，以及 `status`、`missing`、`errors`、`sources`、`provenance` 等可解释信息。只有来源标签、成功布尔值或一段说明的结果，不能冒充已提供行情数据。模块可按单记录或批次组织这些信息，不强制所有页面采用同一深层 JSON 包装。

| 项 | 统一语义 |
| --- | --- |
| `data` | 实际记录或结果；没有值用 `null`，不能用零、空字符串或 AI 内容补数 |
| `status` | 数据状态，与 HTTP 请求是否成功分开；基线为 `ok`、`partial`、`stale`、`unavailable` |
| `missing` | 缺失字段或输入及原因，例如权限不足、未采集、时间未知 |
| `errors` | 安全错误码和可读原因，可注明是否可重试；不含密钥、完整请求 URL、堆栈或私有路径 |
| `sources` | 来源标识、采集方式和必要口径；批次可有多个来源 |
| `provenance` | 原始引用、适配器/计算版本、输入引用和验证状态，支持追踪而非自动认证真伪 |

合法查询无记录可返回空列表并说明查询范围；字段缺失是 `null`。采集失败产生的空结果不能覆盖已有有效记录。已有缓存可返回 `stale` 或 `partial`，必须保留真实时间及失败信息，不能把响应时间当成行情更新时间。不同状态不压缩为“正常/异常”一个灯。

HTTP 4xx 表示参数、访问边界或资源请求问题，5xx 表示服务无法完成请求。外部来源失败但系统可提供明确标注的旧数据时，可返回成功响应与数据状态；不能将服务错误统一伪装成“无行情”。

## 时间、单位和数据层

| 时间 | 含义 | 历史使用规则 |
| --- | --- | --- |
| `event_at` | 记录描述的市场/事件时点 | 不能证明当时已能获得该值 |
| `available_at` | 有证据支持该记录最早可用于研究的时间 | 历史输入必须不晚于研究截止时点 |
| `collected_at` | 本系统或可追溯原系统实际采集到该版本的时间 | 必须保留真实采集时间，不回填到过去 |
| `imported_at` | 旧资产写入新版目标的时间；非迁移记录可为空 | 不替代事件、采集或原始可得时间 |
| `as_of` | 查询、研究或冻结快照的截止时点 | 限定输入可得范围，不表示全部数据同一时刻产生 |

所有时间输出 ISO 8601 时区偏移。`available_at` 可未知；不能仅因下载了历史日 K 就声称当日盘前已可得。首次采集时点、原发布时点和修订时点分别保留：后来的修订不能替换过去决策当时可见的版本。未知可得时间的材料，不直接进入需要严格防穿越的历史样本；模块须明确其限制。日级数据可增加 `trade_date`，冻结证据可增加 `snapshot_id`，不通过把日期补成零点虚构精确时间。

价格标明人民币元，成交量标明股或手，成交额/市值标明元或明确换算单位，涨跌幅标明百分数。`1.25` 表示 `1.25%` 时必须有单位说明，不与比例 `0.0125` 混用。前端可换算万元、亿元展示，同时保留可查看的原单位。复权、指数口径和分类版本跟随记录或数据集契约；不同口径不能只凭代码和日期合并。

`kind=direct` 表示适配器标准化的直接数据；`kind=derived` 表示由输入计算的结果，必须记录输入引用、算法与版本；AI 解读独立保存结构化结论、证据引用、模型/提示版本和失败状态，不能覆盖事实字段。综合计算仍受输入质量、缺失和时间约束，不能因公式算出数字就变成已验证事实。

## 合成示例：直接行情与派生收益

以下数据完全合成，不对应真实股票、来源响应或投资结论。示例中的虚构代码、来源引用、时间和值仅说明语义，`validation=synthetic` 不表示已验证实盘数据。

```json
{
  "synthetic": true,
  "status": "partial",
  "data": {
    "instrument_id": "SYNTHETIC_A",
    "kind": "direct",
    "last_price": 12.5,
    "previous_close": 12.0,
    "volume": null,
    "units": { "last_price": "CNY/share", "previous_close": "CNY/share", "volume": "share" },
    "event_at": "2026-10-08T10:00:00+08:00",
    "collected_at": "2026-10-08T10:00:03+08:00",
    "available_at": "2026-10-08T10:00:03+08:00"
  },
  "missing": [{ "field": "volume", "reason": "synthetic_field_not_supplied" }],
  "errors": [],
  "sources": [{ "id": "synthetic_fixture", "method": "generated_example" }],
  "provenance": {
    "raw_ref": "synthetic/quote-001",
    "adapter_version": "example-v1",
    "validation": "synthetic"
  }
}
```

同一合成输入的派生结果可以为：

```json
{
  "synthetic": true,
  "status": "ok",
  "data": {
    "instrument_id": "SYNTHETIC_A",
    "kind": "derived",
    "change_pct": 4.1667,
    "unit": "percent",
    "event_at": "2026-10-08T10:00:00+08:00",
    "collected_at": "2026-10-08T10:00:04+08:00",
    "available_at": "2026-10-08T10:00:04+08:00"
  },
  "missing": [],
  "errors": [],
  "sources": [{ "id": "synthetic_fixture", "method": "generated_example" }],
  "provenance": {
    "input_refs": ["synthetic/quote-001"],
    "required_fields": ["last_price", "previous_close"],
    "calculation": "(last_price / previous_close - 1) * 100",
    "calculation_version": "example-v1",
    "validation": "synthetic"
  }
}
```

原输入成交量缺失不影响该收益公式，但派生对象的可得时间不能早于输入。若昨收缺失或为零，收益应为 `null` 并给出原因；不得计算为 `0%`。这个示例不是要求所有计算都使用四位小数，精度按模块口径确定。

## 新闻、多来源与历史迁移

新闻归并分开保存原始来源记录与聚合事件。去重可利用来源事件 ID、规范链接、发布时间和文本相似度，但每条来源的标题、引用、采集时间、发布时间与修订保留独立关系。相似标题不自动等于同一事件；关联争议或冲突应可复核，不以多来源数量证明事实可靠。

聚合事件与用户收藏、已读、标记和 AI 解读分层。重采集和重新聚类不得清空用户操作。新闻全文不因公开网页可读就写进开源 fixtures，具体获取与存储边界由来源模块记录。

迁移只接受允许来源及可追溯的结果，保存原标识和迁移批次。旧来源标签缺失、混合血缘、时间口径不明时交由迁移规则判定隔离或拒绝；新项目不能把导入时间当成旧数据原始可得时间。用户私有数据进入本地目标空间，不随代码发布。

## 归属与行为验收

后端建立固定本地身份上下文，不信任请求中的任意 `user_id`/`workspace_id`。用户资产查询、修改、任务与文件按归属定位；找到了 ID 仍须检查归属。缓存须包含实际影响结果的归属、参数、口径与时间范围。

后续模块测试至少覆盖：合法零值与空值、单位换算、过期回退、失败不覆盖、来源冲突、新闻多来源去重、修订与历史截止、重复迁移幂等、跨归属 API/worker/文件访问。展示完成不替代这些行为验证。
