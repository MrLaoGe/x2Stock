# XXStock 0.1.0

建立 XXStock 的开源设计基线、项目 Skill 管理和正式版本发布流程。本版本交付设计文档与开发工具，尚无行情业务应用、真实数据迁移或交易执行。

## 新增功能

- 完成项目定位、前后端架构、数据契约、来源能力矩阵、选择性迁移、界面规范、Agent 角色与分阶段路线；提供 MIT 许可和空配置示例。
- 建立项目级 `.agents/skills/` 目录、分类索引、机器可读登记及首个 `github-release` Skill；后续业务 Skill 按模块逐个增加。
- 新增 VERSION、CHANGELOG 和中文版本说明；首次 0.1.0，此后默认仅递增末位，中间段或主版本需用户明确指定。
- 提供本地准备、材料校验和受限发布工具；GitHub Actions 为本次确切提交创建标签与 Release，0.x 设为预发布且不标为 Latest。
- 复用可配置并脱敏的 VoceChat 客户端，Release 核验成功后通知配置频道（默认 #19），消息包含版本、摘要、链接及运行标识。

## 优化改进

- main 和规范版本标签不再发送独立 push 提醒；其他开发分支及非版本标签保留原提醒。
- 版本准备不写远端；发布检查干净提交、事件身份、版本关系和历史材料。已有标签或 Release 冲突停止，同提交重跑复用已成功部分。
- 历史发布说明与元数据禁止改写；主线历史重写停止发布。网络失败不盲目重试，日志不输出凭据、机器人地址或上游错误正文。
- 更新 AGENTS、贡献规范、模块协作、任务台账和交接规范，明确 Skill 发现与发布授权边界。

## 兼容与升级说明

- 新使用者独立配置数据源、AI 与机器人；仓库不包含真实凭据、数据库、缓存或个人研究资产。
- 正式 main 的每批更新须升版并附中文说明，文档和 Skill 更新也适用；失败恢复、开发分支和无变更同步不另升版。
- 当前仍处于阶段 0；下一业务模块为数据中心与迁移，尚未实现采集、API、页面、产品 Agent、回测或自动交易。
- Release 成功但通知失败时保留 Release；人工重跑可能重复消息，需依据运行标识核对。正式推送后的验收结果以 Actions 为准。

## 验证结果

- 合成测试覆盖初次发布、整数版本比较、默认末位递增、显式升级、材料一致、确切 SHA、标签／Release 冲突、重复执行和部分失败恢复。
- 通知测试覆盖最终消息、main／版本标签去重、开发分支与其他标签、配置优先级、秘密脱敏、HTTP 协议错误及超时不重试。
- 公开资产、相对链接、UTF-8、Skill frontmatter／索引／引用和版本材料由本地校验与主线工作流验证。
- 独立 Agent 使用临时合成 Git 仓库与模拟远端审查发布场景；真实 Release 与频道投递由本次 Actions 完成并留下结果。
