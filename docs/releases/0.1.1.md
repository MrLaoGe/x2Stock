# x2Stock 0.1.1

本版将项目统一为 x2Stock，并交付可从完整公开仓库启动的 Windows 免安装空工作台。

## 新增功能

- Windows x64 桌面工作台：下载完整项目后双击根目录 `启动.bat`，程序及完整运行资源保存在 `desktop-runtime/win-x64`；浏览器前端用于开发调试。
- 简体中文、繁体中文和英文界面，默认简体中文，语言选择即时生效并保留本机偏好。
- 桌面更新检查、整体项目下载校验、用户确认更新、恢复与回退。
- 公开配置、数据来源、接口契约和本地校验工具。

## 优化改进

- 新路线以用户选择的新模块为起点，先定义功能和所需数据，再评估旧资产；不批量迁入未选模块数据，不建立无用途业务表。
- 桌面产品采用 Electron 与 React，后续本地金融后台按需使用 Python、SQLite 和 DuckDB；PostgreSQL 和 Docker Compose 保留为未来服务器部署方案。
- 仓库、当前文档、配置前缀与工具统一为 x2Stock；保留历史发布材料和真实物理路径的审计证据。
- 公开仓库只保留产品运行所需内容，研发内部资料由私有研发仓库维护。

## 问题修复

- 修复本地打包资源路径导致空白界面的问题，以及更新失败和中断时的恢复路径。
- 完善协调锁与最终包体绑定：版本重建必须保留最新主线、确切提交、73 文件清单、源码摘要和独立审查收据，拒绝伪造清单与损坏对象。

## 兼容与升级说明

- 本版仍为 0.x 预发布，EXE 未签名；提供桌面壳、协作与分发能力，尚无行情、数据库、采集、迁移、研究 Agent、回测或交易业务。
- 下载整个项目需包含 Git LFS 的实际文件；Git 克隆需安装 Git LFS。新版 Release 仅附更新元数据，常规交付不另建独立 EXE 压缩包。
- 旧版 0.1.0 为文档仓库且没有更新元数据；本版不能证明从该版自动升级。真实跨版本更新、物理断电、原生整窗截图及系统文字缩放仍待后续验收。
- 用户设置存于独立用户目录；真实凭据、数据库、缓存和个人资产不随开源发布。旧项目仍只读参考，不作为运行依赖。
