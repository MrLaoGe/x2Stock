# ADR 0004：Agent 证据与执行边界

日期：2026-10-08；状态：accepted。

## 背景

多 Agent 可提供不同研究视角，但相同模型可能共享错误；早期直接加入交易会让数据、研究和资金操作耦合。

## 决策

先常规数据与研究，再加入核验、分析、反方和终稿角色。初期仅用户配置的 GPT 模型；确定性检查负责数字、来源、时间和单位。保存证据版本、分歧和失败状态，不以多数同意判定事实。

报告使用冻结快照；量化先回测、样本外与模拟，再单独设计实际执行。研究 Agent 不直接下单，订单必须经过独立确定性风控和执行审计。当前不启用长期运行或自动交易。

## 影响

可逐步验证研究可信度和费用，部分未通过结果会停止发布完整报告；未来执行需单独模块和用户启用，不能绕过本决策。
