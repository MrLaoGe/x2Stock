# ADR 0009：项目名称统一为 x2Stock

日期：2026-10-08；状态：accepted。

## 决策

用户指定项目名称为 `x2Stock`，GitHub 仓库使用 `MrLaoGe/x2Stock`。当前文档、Skill、窗口标题、程序名称、包体、发布说明和通知使用该名称；机器标识使用 `x2stock`，环境变量前缀使用 `X2STOCK_`。

这是现有项目的改名，不新建或覆盖另一个仓库，不重建 Git 历史，不改版本规则。Windows 免安装桌面版仍是正式产品，网页仅用于开发调试；桌面任务负责实际界面和下一包体的更名。

## 兼容与历史

- 已发布 `0.1.0` 的说明、元数据、标签和确切提交保持原样，其中旧名称属于不可改写的发布证据。发布工具仅对这一历史版本接受原名称，新版本必须使用 `x2Stock`，已有 Release 的正文和标题继续逐项匹配。
- 现存工作区和 worktree 的物理目录不在运行过程中移动。目录名不是产品名，文档和脚本不指向尚不存在的新目录。
- 新配置示例使用 `X2STOCK_`；旧配置前缀需要用户或对应模块的迁移工具显式转换。秘密值、真实数据库和研究资产不通过文本批量替换或自动删除。
- 旧预览包不改内容或校验摘要；桌面 PM 将其标记为已被替代，并用新名称重新构建和验收。已有语言配置和用户资产由桌面兼容逻辑保留。
- 各并行 PM 在自己的分支更新新增内容；主线集成重新扫描旧名称，避免将旧品牌带回当前产品。正式发布仍按既有队列执行。

## 验收

确认仓库身份在 GitHub 更名前后保持一致，origin 指向新地址；当前资产除历史证据与明确兼容规则外不残留旧名。验证历史 Release 不被改写、新名 Release 可创建、同版本冲突拒绝及通知标题与链接正确。远端改名、补丁本地验收、主线发布分别记录，不互相替代。
