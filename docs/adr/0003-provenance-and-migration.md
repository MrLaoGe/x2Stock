# ADR 0003：来源准入与历史迁移

日期：2026-10-08；状态：accepted。

历史决定保留。默认保留大量历史行情与新闻的安排已由 [ADR 0006](0006-module-first-new-project.md) 替代；当前先最小应用骨架、再由用户选业务模块，默认不迁移。本文其余来源、隔离和安全约束继续有效，下文保留原决策记录。

## 背景

旧数据同时包含允许来源、禁止来源和无法追踪的混合派生结果。全部重抓成本高，但整体搬库会继承禁用数据和错误口径。

## 决策

只接受 Tushare、东方财富、财联社；排除 zhitu、mairuiapi 历史及新接口，也不默认允许其他来源。按字段/记录可证明来源选择性导入；混合字段能拆分则仅取可信部分，未知部分留空；无法拆分则拒绝。来源标签是溯源证据，不是数据真实性或完整性的保证。

先只读预览，再按数据集导入；记录批次、旧标识、快照和摘要；支持幂等、恢复和不破坏后续更新的回滚。原始事实、派生指标和 AI 解读分开保存；旧派生结果默认重算。历史可用时间未知时不能用于 point-in-time 正式回测。

## 影响

保留大量历史行情与新闻，同时明确概念成员和部分字段缺口；需要来源过滤、对账及血缘检查，不通过猜测补数据。旧报告、任务状态、配置不自动迁入新版。

详见 [来源矩阵](../data/sources.md)、[迁移](../data/migration.md)。
