# ADR 0005：独立 PM 与持久专业对话

日期：2026-10-08；状态：accepted。补充 ADR 0004，不改变产品 Agent 证据和执行边界。

人类批准老板派单后释放，由每项独立 PM 拆分业务、实现与独立验收，创建持久专业对话并负责返工、集成和任务内已授权发布。角色模板覆盖全部模块，开发类 Skill 不构成业务运行器。

实时关系和状态保存 Git 公共目录下忽略的 `.local/orchestration`，不是 UI 树。异步创建待确认不重复派发；取消必须确认停止。文件范围有唯一所有者，独立验收绑定候选。多个 PM 主线发布串行协调，基于最新远端集成复验，锁不因超时抢占，失败恢复先核对持有者和远端事实。

未来业务按原阶段启用。策略研究、程序、回测引擎、实验执行和有效性评估分工；盘前冻结稿不能被盘后结果回填。具体契约见 [协作](../development/collaboration.md)、[角色](../agents.md) 和 [Skill](../../.agents/skills/multi-dialogue-development/SKILL.md)。
