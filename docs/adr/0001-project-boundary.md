# ADR 0001：独立仓库和逐模块推进

日期：2026-10-08；状态：accepted。

## 背景

旧系统是个人定制工作台，功能、运行数据和个人材料混合，已有大量历史资产；公开旧 Git 历史不符合新项目边界。重构需要多次对话逐模块完成。

## 决策

建立 x2Stock 新目录和全新提交历史，采用 MIT；旧项目只读参考，白名单提取算法/测试，真实数据只通过本地迁移工具选择性导入。第一轮只有文档和协作规范，下轮先数据中心与迁移。

名称按当前项目标识显示；初次发布使用原名，更名不改变本决策的原始范围。后续名称与兼容边界见 [ADR 0009](0009-project-name.md)。

## 影响

独立数据库、目录、secrets、任务和端口避免两个项目互相写入；放弃把旧仓库整包公开或直接复制数据库作为新版运行库。阶段推进以模块验收和台账为依据。第三方许可仍需逐项保留。
