# XXStock 总体方案

状态：已确认设计；实施进度见 [任务台账](development/task-ledger.md)。设计基线日期：2026-10-08。

## 定位和边界

XXStock 是独立部署的 A 股研究工作台。近期目标是可信的数据底座与常规研究网页；长期目标是多 Agent 分析、量化验证及可审计执行。每位使用者提供自己的数据源和 AI 凭据，首期单用户，私有数据访问边界预留多用户。

项目使用新目录、独立数据库、数据卷、配置、worker 和全新 Git 历史。旧项目作为功能、算法、测试和本地历史数据的只读参考。保留兼容能力不意味着继续依赖旧运行目录，也不意味着把旧功能全部照搬。

## 功能整合

市场总览、行情研究、新闻与事件、我的研究、报告与复盘、系统设置构成产品导航。个股行情、资金、相关新闻和用户笔记汇入个股研究上下文，减少孤立页面。旧 Skill 蓝图和数据审计作为系统维护能力；会员、积分、CDK 等商业平台能力不进入本方案。

所有旧业务均登记于 [功能审查清单](modules/catalog.md)。状态为“候选”表示还需要模块讨论，不是承诺迁移。接口、字段和算法最终以各模块通过验收的设计为准。

## 本轮交付

- 项目说明、功能清单、架构、API/数据契约、界面规范。
- 三类数据源能力矩阵、旧数据审计证据、迁移和隔离设计。
- 开发/产品两套 Agent 角色、协作规范、任务台账、ADR、交接模板。
- 空配置示例、MIT 许可、公开资产校验工具和 CI。
- 公开文档仓库；不继承旧提交历史或个人运行材料。

本阶段没有业务应用、采集或迁移程序。文档中的接口、表、命令流程和部署布局表示设计，不能当作已运行能力。

2026-10-08 用户追加开发运维需求：先接入 3.0 VoceChat 机器人，对每个仓库 Git push 事件通知可配置频道，当前为 #19。该工具独立实现，地址/密钥脱敏；不扩大 A 股业务模块范围。见 [通知说明](development/git-notifications.md)。

## 推进方法

每次对话选择一个模块，先核对旧实现与来源，再明确输入输出、展示、迁移和验收。完成实现后更新台账和交接；核心选择改变时新增 ADR，不静默改写历史决定。阶段路线与交付门槛见 [roadmap](roadmap.md)。

## 仍需后续核验

Tushare 账户实际权限、东方财富/财联社接口稳定性、字段单位和内容使用边界尚未通过新版实测；不能在设计文档中声明已授权或全量可用。概念历史、部分复权因子、旧派生指标的血缘缺口在数据模块单独处置。券商、实盘模型和长期运行安排在相应阶段另行明确。
