# 数据中心：随已启用模块增长

状态：阶段 0 设计，**未实现**；不是下一轮首个业务模块或前置搬库工程。下一项本体任务为[最小应用骨架](application-skeleton.md)，其后由用户选择业务模块。依据 [ADR 0006](../adr/0006-module-first-new-project.md)、[架构](../architecture.md)与[契约](../contracts.md)。

## 目标与范围

数据中心为已经启用的模块管理配置、显式任务、来源能力、覆盖和质量。能力按真实需求增长，不预先建设所有来源、所有业务表、全数据平台或通用搬库工具。未选模块不初始化业务表、不部署采集/导入任务；三类允许来源不是必须同时接入的交付清单。

用户选模块后先明确新版功能，再确定数据，最后评估旧数据价值；默认不迁移。证券主表、交易日历、日行情、基本面、因子仅是行情类模块可能需要的数据，新闻等模块有各自最小前置，不固定为共同首批。旧 8,991,131 行行情不是必须迁移目标。

## 每个已选模块的数据集设计

| 项目 | 必须明确的结果 |
| --- | --- |
| 功能与依赖 | 用户目标、已选功能、最小前置、功能验收；无关旧能力不纳入 |
| 字段与范围 | 数据集、字段、证券/实体范围、日期区间、粒度、单位、复权/分类口径 |
| 时效与留存 | 更新频率、可接受延迟、覆盖下限、保留/清理规则、历史可用时间证据 |
| 取得方式 | 新采集、有限旧导入、新版重算或不支持；各自收益、成本与限制 |
| 来源与质量 | 允许来源的实际权限/分页/频次、字段血缘、缺失/过期/失败行为 |
| 授权与运行 | 选定范围、任务开关和权限、失败恢复；评估不等于执行授权 |
| 验收与状态 | 功能、数据取得、迁移三类状态分别记录，附独立证据 |

共有功能仅允许评估旧资产价值。若用户另外选择模块、数据集、字段、证券/日期范围及导入批次，才启用[迁移规范](../data/migration.md)。旧指标新版重算，不自动复制旧配置、调度、待执行任务或 AI 报告。旧资产审计只是[参考快照](../data/legacy-audit.md)。

## 页面、接口与任务意图

已启用数据集可展示来源、业务日期、最后成功采集、覆盖与缺口；配置缺失、权限不足、上游失败、过期及历史可用时间未知分别表达。前端只读取新版服务，不直连 provider、不接收密钥或完整旧路径。新采集满足需求可独立交付；可选迁移待定不阻碍功能上线，依赖缺失历史的功能则真实显示受限。

业务接口仍统一 `/api/v1`，具体端点、schema、分页、任务状态机与操作权限随已选模块详细设计冻结。user/workspace 由可信服务端上下文确定，普通请求不能任意改变归属。后台任务有需求才引入独立 worker；不因页面或目录存在就开始采集。来源失败不得用空结果覆盖有效记录，AI 缺配置不影响确定性功能。

## 按启用能力验收

1. 未选模块没有业务表与采集/导入任务；已选模块仅补最小依赖，不扩展成全数据平台。
2. 已启用来源通过字段、证券编码、单位、日期、分页和权限验证；禁止来源、未知血缘和不可拆混合拒绝入库。测试采用合成数据，不公开真实响应。
3. 归属、失败不覆盖、缺失不填零、限流/重试、任务防重复及相关时间边界有行为测试；新采集足够时可独立验收功能。
4. 若启用导入，单独验证稳定快照、staging 隔离、批次幂等、断点、并发发布和安全回滚。有效新数据优先，后续采集不被撤销破坏；验收记录实际数量，不沿用旧审计数。
5. 原始/派生/AI 分层，未知 `available_at` 保持量化限制；历史不足的显示与功能限制可验证。
6. 记录实际交付的构建、业务测试、仓库校验和来源权限缺口；只对已实现能力标记完成。上述数据/迁移验收不作为骨架门槛。

## 开发角色

数据角色定义已选范围的来源、单位、时间和取得方案；后端/前端按冻结契约实施；独立审查检查副作用、归属和时间证据。历史迁移角色只在评估或选定导入时启用，角色覆盖不是任务授权。各角色独立分支/worktree、单一文件所有者；不修改旧项目，不启动旧调度或把真实资产加入公开仓库。产品内研究 Agent 仍为阶段 3。
