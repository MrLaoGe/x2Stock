# 外盒与内盒

`x2Stock` 是公开产品仓库，`x2StockBox` 是私有研发仓库。公开仓库必须能让用户获得当前产品的源码、Windows 运行时、配置示例和用户文档；因此“开源”不能同时意味着隐藏产品源码。隐藏的是研发过程和内部控制材料。

## 外盒保留

- `frontend/`、`desktop/`、`desktop-runtime/`、根启动脚本和依赖锁文件。
- 用户配置模板、数据与接口契约、桌面更新协议、许可证和公开版本说明。
- 合成测试、运行时完整性检查和面向用户的贡献说明。
- 已实现的产品界面和用户可见的功能说明；设计草图与未实现方案不属于外盒。

## 内盒保留

- `.agents/skills/`、`AGENTS.md`、多对话编排和角色模板。
- `docs/adr/`、`docs/development/`、路线、任务台账、内部交接和设计草图。
- GitHub Release、VoceChat/VChat 通知、内部凭据和发布工作流。
- `docs/designs/` 等视觉方案和未实现产品设计留档。

内盒向外盒导出时使用显式白名单，不能把私有目录作为运行依赖。公开仓库已有历史提交包含早期设计材料，本轮不重写公开历史；从本次边界提交开始，新增内容必须通过白名单审查。
