# x2Stock 用户文档

下载完整项目后运行根目录 `启动.bat`。应用运行资源在 `desktop-runtime/win-x64`，界面语言可切换并保留本机偏好。目前是空工作台，没有金融业务模块。

更新检查仅接受官方公开仓库的确切提交、对应版本和校验通过的完整归档。应用更新需用户确认；失败会保留恢复材料，用户设置独立于程序目录。
